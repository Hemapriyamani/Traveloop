
TRAVELOOP ENHANCED FULLSTACK PROJECT

FEATURES
- Dashboard
- Create Trip
- My Trips
- Budget Analytics
- Packing Checklist
- Notes
- React Router Navigation
- Spring Boot Backend
- MySQL Integration

====================================
DATABASE
====================================

CREATE DATABASE traveloop;

====================================
BACKEND
====================================

cd backend

Run:
mvn spring-boot:run

====================================
FRONTEND
====================================

cd frontend

npm install
npm start

====================================
URLS
====================================

Frontend:
http://localhost:3000

Backend:
http://localhost:8080
